## 📥 Instalación y Uso (Sin necesidad de compilar)

Si solo quieres usar la aplicación para probar el rendimiento de tu PC y no quieres lidiar con el código fuente, puedes descargar el ejecutable directamente:

1. Ve a la sección de [**Releases**](https://github.com/Rodrigoabril7/ComponenStressSolution/releases/tag/v1.0.0) (o haz clic en "Releases" en la barra lateral derecha).
2. Descarga el archivo `.zip` de la última versión.
3. Descomprímelo en tu ordenador.
4. Haz doble clic en `ComponenStress.exe` y se abrirá el programa con el panel gráfico.
